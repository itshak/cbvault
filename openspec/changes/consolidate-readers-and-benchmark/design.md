# Design: Consolidate CBH/2CBH readers and establish reproducible performance gates

Phase A is blocking: implement corpus manifest, fetch/verify tooling, coverage census, benchmark harness and paired GitHub Actions runner. Use docs/benchmark-corpus.md. Keep private gold gate separate. Run baseline against v0.2.0 and capture full output/allocations before Phase B.
Phase B: inspect upstream oschess 6f2d1ee5fd and Morphy e61f2af6c1/a8cfe6eaae only in specifier room; independent implementation in Rust. Share I/O/window machinery without flattening format semantics. In twocbh/segment.rs remove path clone and test allocation counts; store validated ranges to avoid repeated parsing only if safe. Check offset arithmetic with checked addition. Replace wave barriers in bridge/convert.rs with bounded ordered streaming if paired tests improve; no unbounded queues. Poll cancellation within workers and ensure no records delivered after acknowledged cancellation. Benchmark direct mmap slices vs bulk positioned reads in both generations, record order vs physical offset order, with bounded reordering.
Search: benchmark ID-only streaming/pagination, lazy or interned v2 entity resolution, reusable thread pools, and per-operation memory budget; avoid per-game owned strings. Preserve public contracts, add fallible generation-aware methods and deprecate panic-prone classic accessors. Audit mapping safety under external mutation; use stable snapshots or unmapped access where immutability cannot be ensured; no claim that metadata checking makes unsafe mapping safe. Benchmark access-pattern-specific OS hints.
Provenance: existing MIT ports retain notices; new infrastructure original; later upstream facts clean-room. No source code copied. Gigachess remains the sole chess core.
Budget: zero hot-loop allocations where existing contracts promise zero; deterministic byte parity hard gate. Paired same-run base/head trials, warmups and alternating repetitions, medians and dispersion; throughput regression >5% or latency >10% is a provisional investigation threshold, not a noisy single-run release veto. Record peak RSS, cancellation latency, worker scaling and disk footprint; stabilize thresholds from baseline. Do not regress classic or archives to improve v2.

Acceptance: no unsupported feature may be advertised; document failed experiments and report absent real-data gates explicitly.
