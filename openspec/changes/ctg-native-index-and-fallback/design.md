# Design: CTG native CTO lookup and persistent fallback

Research jja (GPL), Daydreamer/ctgreader (provenance uncertain despite MIT label), BrainLearn and actual independently created books in the specifier room; record format facts without code. Implementer sees only frozen spec. Validate native results against independent scan on every reachable key for small books and stratified millions of probes plus misses on large books; audit collisions, mirrored positions, en passant, bounds and malformed indexes. A native negative is authoritative only for supported, validated index semantics; otherwise fallback or typed uncertainty. Opening remains read-only; sidecar cache explicitly located outside source, versioned, hashed/fingerprinted, checked, atomic publish, cancellation cleanup. Use configurable memory and thread budgets and optional mmap; native count may be unknown without full scan. Benchmark cold/warm open, lookup p50/p95/p99, RSS, disk and cache rebuild, on public CTG if available and local PowerBook/HIARCS/custom books; no redistribution of licensed books. Goals <200 ms native open and <1 ms warm p95 are provisional, measure rather than claim. All new code original or clean-room.

Acceptance: no unsupported feature may be advertised; document failed experiments and report absent real-data gates explicitly.
