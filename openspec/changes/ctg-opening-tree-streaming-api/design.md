# Design: CTG opening-tree API, streaming and hot-path optimization

Depends on reader baseline and native/fallback index change. In cbvault/src/book.rs expose reusable handle and typed one-level query returning moves2, child result counts oriented white/black/mover, ratings, evaluation, annotations/recommendations, missing vs zero vs corrupt, optional continuation status. Preserve stored order, unknown move bytes and raw semantics. Avoid decoding child moves for stats-only probes. In cbvault-chess/src/ctg.rs generate legal moves once per position, precompute piece ordinal lookup, use fixed-capacity keys, evaluate direct validated board construction in gigachess (no second chess core). Streaming iterator/callback over borrowed raw entries, opt-in decoded boards, bounded batches/parallel, progress and cancellation; distinguish whole-book traversal from direct probes. Verification can stream without building index unless child lookup requested. CLI delegates to library orientation logic. Test white/black stats, castling, promotion, symmetry, transpositions, missing children, unknown flags, corrupt pages and real-book gold. Provisional warm tree p95 <5 ms; compare same workload, allocations and counts.

Acceptance: no unsupported feature may be advertised; document failed experiments and report absent real-data gates explicitly.
